# Petro Card Balance Checker

A mobile-friendly web application for reading Petro-Canada gift card screenshots,
extracting card information, and helping users check remaining card balances.

## Planned Features

- Select multiple screenshots from iPhone
- Extract card numbers and security codes
- Review and correct OCR results
- Check card balances
- Identify used / zero-balance cards
- Calculate total remaining balance
- Mobile-friendly interface
- Privacy-first local image processing

## Development

This project is being developed as a web application using HTML, CSS, and JavaScript.
